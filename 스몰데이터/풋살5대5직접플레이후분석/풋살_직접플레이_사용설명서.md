# FUTSAL PLAY LAB — 고등학생 스포츠 데이터 실습

## 게임 실행
1. `futsal_5v5_manual_game.html` 파일을 Chrome 또는 Edge에서 엽니다. 별도의 서버나 인터넷 연결이 필요하지 않습니다.
2. 오른쪽 **경기 시작**을 클릭합니다.
3. 파란색 BLUE 팀의 선택 선수(기본 A5)를 조작해 주황색 ORANGE AI 팀과 5대5로 대결합니다.
4. 경기는 **4분**이며, 일시정지·재시작이 가능합니다.

## PC 조작
- `WASD` 또는 방향키: 이동
- `J` 또는 스페이스: 패스 (수비 시 가까이 접근해 태클)
- `K` 또는 엔터: 슈팅 (공 소유 필요)
- `L` 또는 `Q`: 조작 선수 변경
- `Shift` 누르기: 질주 (에너지 소비)
- 경기장 클릭: 조작 선수의 이동 목표 지정
- BLUE 선수 명단 클릭: 해당 선수로 변경

## 스마트폰 / 태블릿
- 화면에 표시된 **가상 조이스틱**을 손가락으로 드래그해 이동합니다.
- 패스/태클, 슈팅, 선수 전환, 질주 버튼으로 제어합니다.
- 질주 버튼은 누르는 동안만 발동합니다.

## 팀 구성
- **BLUE 팀 A1~A5**: 사용자 조작 1명 + AI 동료 4명
- **ORANGE 팀 B1~B5**: AI 상대 선수 5명
- 공을 가진 BLUE 팀 동료가 변경되면 조작 선수가 자동 전환될 수 있습니다.

## 히트맵 및 위치 좌표
- 풋살 경기장: 가로 40m, 세로 20m
- `위치 히트맵 표시`: 경기 중 수집된 좌표의 밀도를 파랑(낮음)~빨강(높음)으로 표현
- 분석 대상: 전체 10명 / BLUE 팀 / ORANGE 팀 / 개별 선수 선택
- 이동 궤적 보기 가능

## CSV 다운로드 / Python 데이터 분석
- **10명 전체 위치 데이터 CSV 다운로드**를 눌러 경기 기록을 저장합니다.
- 다운로드 파일 이름은 `futsal_5v5_manual_match_positions.csv`입니다.
- 14개 열: `sample_id,game_time_sec,team,player_id,number,role,x_m,y_m,x_normalized,y_normalized,ball_x_m,ball_y_m,ball_owner,source`
- `source`에서 `human-control`은 직접 조작된 선수, `AI-match`는 AI 선수의 기록입니다.
- 기존 `futsal_5v5_python_analyzer.html` 웹앱 및 `futsal_5v5_colab_analysis.ipynb` 노트북에 그대로 업로드해 분석할 수 있습니다.
- 좌표 간 직선거리의 합은 실제 이동 경로보다 적게 계산될 수 있습니다.

## 수업 실습 아이디어
- 같은 포지션의 사용자 조작 기록과 AI 선수 이동 기록의 히트맵 비교
- 패스 중심 플레이와 슈팅 중심 플레이 후 선수 활동 구역 비교
- 팀별 수비·중앙·공격 활동 비율, 평균 이동속도 및 표본 간격 효과 분석

> 교육용 가상 풋살 게임입니다. 선수 속도와 이동 경로는 실제 스포츠 경기나 선수 추적 기록을 반영하지 않습니다.
